HTML structure

HTML has a structure to start of every html code!

<!DOCTYPE html>

This is the decleration! It tells the browser that this is an HTML5 file. And no, you cannot code HTML5 and HTML4 together.

<html>

This is basically the container. Some people put <html lang=en>. It contains all the HTML code.

<head> is the tab and contains the data. Under this, you can link your CSS file and name your website. The <title> is the title of your website.

<body> is the container of the web page. It contains the Headings, paragraph and other stuff.

Every tag has a closing tag. so for <body>, there is a </body>

The final structure should look like this

<!DOCTYPE html>

<html>

<head>

<title> you title </title>

</head>

<body>

Your content goes here

</body>

</html>
