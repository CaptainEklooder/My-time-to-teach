  3. The <a> tag

    4. The <a> tag is to link links

    It is formated like this

    <a href="randomlinktofiles.com">Uhh..67</a>

    The Uhh..67 is the name of the link. For example, if I had to link a source because I types my essay in HTML for whatever reason, then inseated of it being just the full link, it would the name of the website or whatever you choose to name it.

    Fun fact, you use this to link other html files together.

  4. The <ul> and the <ol> tags

    5. The <ul> tag stands for Unordered List (WOW! SO GENIUS)

    To list the items in <ul> list, you need <li> which stands for List Item. Man, whos making these names, this is pure genius.

    Unordered lists are used when you are just bulleting some thing down. For example, you wouldn't use Unordered list for a recipe book with instructions But you would use unordered list for the ingredients of a recipe because it doesn't matter what order you buy them from in a grocery store

    The <ol> tag is the Ordered List. Bruh, this is so smart! My brain can't keep up with it

    You would use <li> to list items in the ordered list as well.

    Ordered lists of for lists that need to be in order. Like a recipe.
